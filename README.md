# ☕ Coffee Shop

## 📖 Descrição
O **Coffee Shop** é uma página web desenvolvida para uma cafeteria fictícia localizada dentro de uma biblioteca. O objetivo do projeto é apresentar informações sobre o estabelecimento, divulgar receitas de café e permitir que os usuários façam reservas de mesas por meio de um formulário.

Durante o desenvolvimento, foram aplicados conceitos fundamentais de desenvolvimento front-end, como estruturação semântica em HTML, estilização com CSS e organização do código utilizando a metodologia **BEM (Block Element Modifier)**.

## 🚀 Funcionalidades

- Página inicial com apresentação da cafeteria.
- Seção com receitas de café incorporadas do YouTube.
- Formulário para reserva de mesas.
- Rodapé com informações de contato e redes sociais.
- Layout organizado utilizando Flexbox e posicionamento em CSS.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS
- Flexbox
- Posicionamento CSS
- Metodologia BEM
